# Blunder P7–P12 capability report

## Result

Blunder’s second capability wave is implemented as one native system. Autonomous proposals now pass deterministic and model review, source evidence is compiled by semantic range, validation negotiates an operating-system process boundary, the IDE includes a checkpointed semantic editor, outcomes learn from observed repository state, and private publication has a continuous proof workflow.

## Isolation statement

The Python audit boundary is always required. A direct Windows launch can add Job Object enforcement; this Codex-hosted session returned `BLOCKED_BY_PARENT_JOB_POLICY` because the enclosing host already owns the process Job and refuses nested assignment. Blunder reports `kernelProcessLimit: false` in that state. It does not claim AppContainer, virtual-machine, or hostile-native-code isolation.
