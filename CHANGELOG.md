# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added
- Coverage measurement job (`coverage` over the `unittest` suite) reporting `blunder` package line coverage in the CI job summary, with a `--fail-under` floor.
- `CHANGELOG.md` following the Keep a Changelog format.
- Versioned Blunder vNext service contracts, durable task events, orchestration foundations, and a native desktop work surface.
- Constitutional autonomous promotion policies, strict evidence decisions, tamper-evident promotion records, and CLI/API/desktop inspection surfaces.
- Standing-policy isolated mission launch, lifecycle synchronization, review artifacts, owned cancellation, and exact task-bound review-tree integration.
- Multi-layer Engineering Graph, typed dynamic teams and mailboxes, research/design workflow, equal-cost resource comparison, and offline memory consolidation.

### Changed
- The completed Fractal Sovereign roadmap is now treated as the CCOS governance substrate for the vNext desktop program.
- Promotion no longer has a manual or pending-proof bypass; missed evidence thresholds remain blocked or exact `NO_CHAMPION`, while source integration and external effects remain separate.
